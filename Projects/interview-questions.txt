Q1: What is a SOC?
A Security Operations Center (SOC) is a centralized unit responsible for monitoring, detecting, analyzing, and responding to cybersecurity incidents in real time. The SOC team uses tools like SIEM, EDR, IDS/IPS, and threat intelligence platforms to identify suspicious activity and protect organizational assets.

The primary goal of a SOC is to reduce the time to detect (MTTD) and time to respond (MTTR) to threats.

---

Q2: What are the main responsibilities of a SOC Analyst?
Ans: 
Monitor security alerts
Triage alerts
Investigate suspicious activity
Analyze logs (Windows, Linux, Firewall, Proxy)
Escalate incidents
Document findings
Contain threats
Recommend remediation

---

Q3: What is alert triage?
Alert triage is the process of analyzing a security alert to determine:
Is it a false positive?
Is it malicious?
What is the severity?
What action is required?
It involves validating logs, checking context, and assessing impact.

🔹 PART 2: WINDOWS LOG ANALYSIS
---------------------------------
Q4: What is Event ID 4625?
Event ID 4625 indicates a failed login attempt in Windows. It includes:
Account name
Logon type
Source IP address
Failure reason
Repeated 4625 events may indicate brute-force attempts.

---

Q5: What is Event ID 4624?
Successful login event.
Important fields:
Logon Type
Source Network Address
Account Name

---
Q6: What does Logon Type 10 mean?
Remote Interactive Login (RDP).
If many 4625 type 10 attempts appear → possible RDP brute-force attack.

---

Q7: How would you detect brute force in logs?
Look for repeated 4625 failures
Same username targeted
Same source IP
High frequency within short time
Check if followed by 4624 (successful login)
If yes → likely compromise.

Q12: Where are authentication logs stored in Linux?
/var/log/auth.log (Ubuntu)
/var/log/secure (CentOS)

---

Q13: How to detect SSH brute force in Linux?
Check auth.log for:
        Failed password for invalid user
        Failed password from <IP>
Count repeated attempts from same IP.

---

Q14: What is sudo?
Allows users to execute commands as root.
Abuse of sudo can indicate privilege escalation.
