Here is a comprehensive list of 50 SOC Analyst interview questions, organized by category, with detailed answers to help you prepare.

## Tier 1 & General SOC Fundamentals

### 1. What is a SOC, and what are its primary functions?
**Answer:** A Security Operations Center (SOC) is a centralized team that monitors, detects, responds to, and remediates cybersecurity threats 24/7. Primary functions include:
- **Asset discovery & inventory**
- **Log aggregation & normalization** (SIEM)
- **Alert triage & validation**
- **Incident response**
- **Threat hunting**
- **Vulnerability management support**
- **Compliance reporting**

### 2. Explain the difference between an event, an alert, and an incident.
**Answer:**
- **Event:** Any observable occurrence in a system or network (e.g., a user login). Not necessarily malicious.
- **Alert:** A notification generated by a security tool (SIEM, EDR, IDS) when a specific rule or threshold is met.
- **Incident:** An alert that has been verified as malicious or violating policy, requiring response actions.

### 3. What is the Cyber Kill Chain? Name its phases.
**Answer:** A model by Lockheed Martin describing the stages of a cyberattack:
1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation
5. Installation
6. Command & Control (C2)
7. Actions on Objectives

### 4. Explain the MITRE ATT&CK framework. How do SOC analysts use it?
**Answer:** MITRE ATT&CK is a knowledge base of adversary tactics, techniques, and procedures (TTPs). Analysts use it to:
- Map alerts to specific techniques (e.g., T1059 – Command and Scripting Interpreter)
- Understand attacker behavior
- Write detection rules (Sigma, YARA)
- Prioritize gaps and hunt for known TTPs.

### 5. What is the Pyramid of Pain?
**Answer:** A concept showing the difficulty of indicators for attackers to change:
- **Trivial:** Hash values (easy to change)
- **Easy:** IP addresses
- **Simple:** Domain names
- **Annoying:** Network/host artifacts
- **Challenging:** Tools
- **Tough:** TTPs (most valuable to detect)

### 6. What is a SIEM? Give examples.
**Answer:** Security Information and Event Management – aggregates logs, normalizes data, correlates events, and generates alerts. Examples: Splunk, QRadar, Sentinel, LogRhythm, ELK Stack.

### 7. What is an EDR? How is it different from antivirus?
**Answer:** Endpoint Detection and Response – provides continuous monitoring, behavioral analysis, threat hunting, and response capabilities on endpoints. Unlike legacy AV, EDR records telemetry (process trees, network connections) and allows live remediation (isolate, kill process).

### 8. What is false positive, false negative, true positive, true negative?
**Answer:**
- **TP:** Malicious activity correctly alerts.
- **FP:** Benign activity triggers alert (wastes time).
- **TN:** Benign activity correctly no alert.
- **FN:** Malicious activity missed (most dangerous).

### 9. How do you prioritize alerts in a SOC? (Triage)
**Answer:** Using a combination of:
- **Asset criticality** (Crown Jewels vs. test server)
- **Alert severity** (Critical, High, Medium, Low)
- **Confidence level** (rule fidelity)
- **Impact assessment** (data exfiltration, lateral movement)
- **Business context** (maintenance window vs. production)

### 10. What is the difference between IDS and IPS?
**Answer:**
- **IDS (Intrusion Detection System):** Monitors and alerts on malicious traffic (passive).
- **IPS (Intrusion Prevention System):** Sits inline and can block/drop malicious packets (active).

## Incident Response & Investigation

### 11. Walk me through the incident response lifecycle (NIST 800-61).
**Answer:**
1. **Preparation** – tools, playbooks, training
2. **Detection & Analysis** – triage, scoping
3. **Containment** – short-term (isolate host) and long-term (patch, block)
4. **Eradication** – remove malware, close backdoors
5. **Recovery** – restore from clean backup, monitor
6. **Post-Incident (Lessons Learned)** – improve detection, update playbooks

### 12. What steps do you take when you receive a phishing alert?
**Answer:**
1. Verify if the user clicked or submitted credentials.
2. Extract indicators: sender email, URL, attachments, headers.
3. Sandbox the URL/attachment.
4. Check for any successful logins or mailbox rules created.
5. Reset user password if compromised.
6. Block sender/domain at email gateway.
7. Search for other recipients of same email.
8. Document and escalate if widespread.

### 13. How do you investigate a suspicious process on a Windows endpoint?
**Answer:**
- Get process tree (parent-child relationships)
- Check command line arguments
- Look for network connections (netstat, Sysmon Event 3)
- Check hash on VirusTotal or sandbox
- Look for persistence (run keys, scheduled tasks, services)
- Compare with baseline – is it signed? Known?

### 14. What is the difference between containment, eradication, and recovery?
**Answer:**
- **Containment:** Stop the bleeding – isolate host, revoke tokens, block IP.
- **Eradication:** Remove root cause – delete malware, patch vulnerability, disable compromised accounts.
- **Recovery:** Return to normal operations – restore data, reboot, reconnect to network.

### 15. How would you detect lateral movement in a network?
**Answer:**
- Unusual RDP or WinRM logins (Event 4624 with logon type 10, 3)
- PsExec or WMI activity (Event 5156, 4688)
- Pass-the-hash artifacts (Event 4624 with certain authentication packages)
- Unusual SMB connections (to admin shares C$, ADMIN$)
- Network scans from an internal host

### 16. What is a hash? How is it used in investigations?
**Answer:** A hash (MD5, SHA1, SHA256) is a cryptographic fingerprint of a file. Used to:
- Check file reputation (VirusTotal)
- Identify known malware
- De-duplicate files in large collections
- Correlate across multiple alerts

### 17. Explain the difference between TTPs, IOC, and IOA.
**Answer:**
- **IOC (Indicator of Compromise):** Artifact observed after a breach (hash, IP, domain). Easy to detect but also easy to change.
- **IOA (Indicator of Attack):** Behavioral pattern indicating an attack in progress (e.g., unusual process spawning cmd.exe). Harder to evade.
- **TTPs (Tactics, Techniques, Procedures):** How attackers operate – most valuable for hunting.

### 18. What is a playbook? Why are they important?
**Answer:** A predefined, step-by-step response procedure for a specific alert type (e.g., ransomware, phishing). They ensure consistent, fast, and complete investigations, reduce human error, and help new analysts learn.

### 19. How do you handle a ransomware alert?
**Answer:**
1. Identify affected host(s) via file extension changes, ransom note, or EDR alert.
2. Immediately isolate host from network (disable NIC, firewall rule).
3. Block C2 domains and hashes at perimeter.
4. Identify encryption stop-gap (e.g., kill process, shut down if necessary).
5. Determine patient zero – how did it enter?
6. Check for lateral movement.
7. Restore from offline backups.
8. Escalate to IR lead.

### 20. What is the difference between a live response and a forensic image?
**Answer:**
- **Live response:** Collect volatile data (RAM, processes, network connections) from a running system. Fast, less intrusive.
- **Forensic image:** Bit-for-bit copy of disk. Preserves evidence integrity, allows deep analysis offline, takes longer.

## Log Analysis & SIEM

### 21. What Windows Event IDs are most important for a SOC analyst?
**Answer:**
- **4624:** Successful logon
- **4625:** Failed logon (brute force)
- **4648:** Logon using explicit credentials (RunAs)
- **4672:** Special privileges assigned (Admin)
- **4688:** Process creation
- **4689:** Process termination
- **4698:** Scheduled task created
- **4702:** Scheduled task updated
- **4720:** User account created
- **4732:** Member added to security-enabled local group
- **5140:** Network share accessed
- **5145:** Detailed file share
- **5156:** Network connection allowed

### 22. How would you detect a brute force attack using Windows logs?
**Answer:** Query for Event ID 4625 (failed logon) with many attempts from one source IP across multiple accounts (account lockout thresholds), or one account with many source IPs (password spray). Look for failure code 0xC000006A (bad password) or 0xC0000234 (account locked).

### 23. What is log normalization in a SIEM?
**Answer:** The process of mapping different log formats (Windows, Linux, Firewall, AWS) into a common schema – e.g., all timestamps become UTC, all source IP fields map to `src_ip`. Allows correlation across different data sources.

### 24. How would you investigate a spike in outbound traffic from a server?
**Answer:**
1. Identify top talker IP and port.
2. Check destination reputation (threat intel).
3. Look for data volume over time – exfiltration pattern.
4. Inspect process responsible (netstat + process name).
5. Check if server is part of a botnet or compromised.
6. Review recent anomalies on that host (scheduled tasks, new services).

### 25. What is a correlation rule? Give an example.
**Answer:** A logic that combines multiple events across time or sources to detect an attack pattern. Example: (Failed logon >10 in 5 minutes from same IP) AND (Successful logon from that IP later) = Password guessing success.

### 26. How do you reduce false positives in a SIEM?
**Answer:**
- Tune threshold (e.g., 5 failed logins → 15)
- Exclude known service accounts or maintenance IPs (whitelisting)
- Add context (time of day, asset criticality)
- Use alert grouping and suppression
- Convert to anomaly-based detection with baselines

### 27. What is the difference between network-based and host-based detection?
**Answer:**
- **Network-based (NIDS/NTA):** Monitors traffic – detects scans, C2 beacons, data exfiltration. Blind to encrypted payloads.
- **Host-based (HIDS/EDR):** Monitors OS events – process creation, registry, file changes. Can see encrypted content after decryption but only per endpoint.

### 28. How do you investigate a suspicious scheduled task?
**Answer:** Check task name, triggers, actions (what binary/script), run-as user. Look for tasks created outside maintenance windows. Review Event ID 4698 (create), 4702 (update). Compare with baseline – is it expected?

### 29. What is the difference between Sysmon and Windows Event Logs?
**Answer:** Sysmon (System Monitor) provides deeper telemetry: process creation with full command line, network connections, file creation time changes, process access (e.g., LSASS access), driver loads. Not enabled by default.

### 30. How would you detect data exfiltration in logs?
**Answer:**
- Large outbound traffic volumes to rare external IPs
- Unusual protocols (DNS tunneling, HTTPS to non-standard ports)
- Repeated access to sensitive file shares followed by uploads
- Base64-encoded data in DNS queries
- Outbound connections to cloud storage (Dropbox, Google Drive) from unexpected hosts

## Network Security & Analysis

### 31. Explain the difference between TCP and UDP. Which is more dangerous from a SOC perspective?
**Answer:** 
- **TCP:** Connection-oriented, reliable, sequenced. Used for web, email, file transfer.
- **UDP:** Connectionless, faster, no guarantee. Used for DNS, streaming, VoIP.
Both can be abused. UDP is harder to track but easier to spoof. TCP is easier for C2 (reverse shells).

### 32. What are the three-way handshake and four-way teardown in TCP?
**Answer:**
- **Handshake:** SYN → SYN-ACK → ACK (establishes connection)
- **Teardown:** FIN → ACK → FIN → ACK (or RST for abrupt close)

### 33. How can you detect C2 (command & control) traffic using network analysis?
**Answer:**
- Beaconing patterns (periodic, regular intervals)
- Unusual DNS TTLs (short-lived domains)
- DNS requests for rare domains or DGA-generated names
- Traffic to known malicious IPs (threat intel)
- TLS certificates with unusual fields
- JA3/S signatures of known malware

### 34. What is a DNS tunneling attack? How to detect it?
**Answer:** Encapsulating data inside DNS queries/responses to bypass firewalls. Detection:
- Long or random subdomains (e.g., `exfiltrateddata1234.malicious.com`)
- High volume of TXT records or subdomain queries
- Abnormal packet sizes (DNS normally small)
- Unexpected hosts making DNS queries (IoT, printers)

### 35. What is the difference between Wireshark and tcpdump?
**Answer:** Both capture packets. 
- **tcpdump:** CLI, lightweight, scriptable, runs on headless servers.
- **Wireshark:** GUI, powerful filtering, protocol dissection, analysis.

### 36. How would you identify a port scan from firewall logs?
**Answer:** Single source IP connecting to many destination ports (same host or many hosts) with SYN packets and few SYN-ACK replies. Look for many connection attempts without completion (half-open scans).

### 37. Explain the difference between IDS alert types: signature-based vs. anomaly-based.
**Answer:**
- **Signature-based:** Matches known attack patterns (e.g., Ettercap string). Low false positives but misses zero-days.
- **Anomaly-based:** Baselines normal traffic and alerts on deviation. Catches novel attacks but higher false positives.

### 38. What is a reverse shell? How can you detect it?
**Answer:** Attacker’s machine listens, victim connects outbound (bypasses inbound firewall). Detection:
- Child process of browser/office app spawning `cmd.exe` or `powershell` with network connection
- Outbound shell-like commands (e.g., `/bin/bash -i`)
- Unusual parent-child relationships (winword.exe → cmd.exe → netcat)
- EDR telemetry showing socket creation

### 39. What is the difference between HTTP and HTTPS from a detection standpoint?
**Answer:** HTTP traffic is cleartext – you can see URLs, user agents, payloads. HTTPS is encrypted – only metadata (IP, port, SNI, TLS handshake). Detect HTTPS threats via JA3 fingerprints, certificate analysis, and decryption (if org permits).

### 40. What is a beaconing interval? Why is it important?
**Answer:** The regular time delay between C2 check-ins. Important because regular periodic traffic (e.g., every 60 seconds) is abnormal for legitimate software and can be detected using time-series analysis on netflow.

## Threat Intelligence & Hunting

### 41. What is the difference between strategic, tactical, and operational threat intelligence?
**Answer:**
- **Strategic:** High-level, for executives – trends, risks, adversary motivations.
- **Tactical:** TTPs, IOCs – for SOC analysts to write detections.
- **Operational:** Specific campaigns, active attacks – for immediate response.

### 42. What is threat hunting? How is it different from alert-driven investigation?
**Answer:** Proactive, hypothesis-driven search for undetected threats. Unlike reactive alert triage, hunting assumes compromise already exists. Uses analytics, TTPs, and baselines.

### 43. What is a DGA (Domain Generation Algorithm)? How to detect it?
**Answer:** Malware generates pseudo-random domains for C2 using a seed (date, Twitter trending topics). Detection:
- High NXDOMAIN DNS responses
- Domains with random character distribution (entropy)
- Frequent registration of similar domains
- No passive DNS history

### 44. What is a TIP (Threat Intelligence Platform)? Example?
**Answer:** Centralized system to ingest, normalize, and operationalize threat feeds (IOCs, TTPs). Examples: MISP, ThreatConnect, Anomali.

### 45. How do you validate an IOC before blocking?
**Answer:**
1. Check confidence source (reputable vendor, internal research)
2. Search within your environment (SIEM) for historical hits
3. Verify false positive potential (is it a CDN IP? Public DNS?)
4. Check age (IOCs older than 30 days less reliable)
5. Sandbox the indicator (if URL/file)

### 46. Explain the diamond model of intrusion analysis.
**Answer:** A framework showing the relationship between four core components of an intrusion:
- **Adversary** (attacker)
- **Capability** (tool/malware)
- **Infrastructure** (IPs, domains)
- **Victim** (target)
Edges represent how they relate (e.g., adversary uses capability against victim via infrastructure).

## Tools & Practical Knowledge

### 47. How do you investigate a suspicious PowerShell command?
**Answer:**
- Get full command line from Event 4688 or PowerShell logs (ScriptBlock Logging).
- Check for encoded commands (`-EncodedCommand`).
- Decode base64 string (CyberChef).
- Look for download cradle (`IEX (New-Object Net.WebClient).DownloadString()`).
- Check parent process (browser, Office, scheduled task).
- Run command in sandbox if safe.

### 48. What is the difference between a STIX and TAXII?
**Answer:**
- **STIX (Structured Threat Information eXpression):** Language for describing cyber threat intelligence (IOCs, TTPs, campaigns).
- **TAXII (Trusted Automated eXchange of Intelligence Information):** Protocol to transport STIX data.

### 49. How would you detect privilege escalation on Windows?
**Answer:**
- Event 4672 (special privileges assigned) for unexpected accounts
- `whoami /priv` differences before/after exploit
- Process accessing LSASS (Event 4656, Sysmon Event 10)
- New admin account creation (Event 4720 + 4732)
- Scheduled tasks or services running as SYSTEM
- DLL sideloading or weak service permissions (Sysinternals AccessChk)

### 50. You see an alert “Potential Pass-the-Hash (PtH) attack.” What do you do?
**Answer:**
1. Verify source host and destination.
2. Look for logon type 9 (NewCredentials) or 3 (Network) without clear text password.
3. Check if destination process is privileged (LSASS, SAM).
4. Look for tools like Mimikatz, Invoke-TheHash, or wmiexec.
5. Immediately isolate compromised host.
6. Reset all credentials of logged-on users.
7. Search for lateral movement from same source.
8. Disable NTLM if possible (long-term hardening).
